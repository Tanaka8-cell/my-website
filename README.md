# Tanaka Kazonda · Portfolio Website

An elegant, editorial single-page portfolio.

## What's inside

- `index.html` is the main page (hero, about, winning, CV, projects, atlas, contact)
- `styles.css` is all the styling
- `script.js` handles scroll animations and active nav highlighting
- `images/` holds your project and profile images

## How to view it locally

Double-click `index.html`. It opens in your browser. No build step needed.

## How to publish it for free

**Easiest option, Netlify Drop:**

1. Go to https://app.netlify.com/drop
2. Drag the whole `portfolio` folder onto the page
3. Done. You get a live URL in about ten seconds
4. Sign up for a free Netlify account to rename it (for example `tanakazonda.netlify.app`)

**Other options:**

- GitHub Pages: create a repo called `tkazonda.github.io`, upload these files, your site goes live at `https://tkazonda.github.io`
- Vercel: same drag-and-drop as Netlify, at https://vercel.com

## How to edit content

Open `index.html` in any text editor (Notepad, VS Code, TextEdit). Search for the text you want to change. Sections are labelled with comments like `<!-- ABOUT -->`.

To swap images, drop a new file into `images/` using the same filename, or update the `<img src="...">` reference.
